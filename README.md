# Aeroacoustics Case Study

Coursework for Aero-acoustics (UFMEWD-15-M), UWE Bristol (2024 to 2025).

A CFD based aeroacoustic study of a multi element aerofoil (S1210 with slat) in ANSYS Fluent, using LES, k omega SST and DES turbulence models, with far field noise predicted through the Ffowcs Williams and Hawkings (FW-H) acoustic analogy.

## Files
| File | Description |
|---|---|
| `Aero_Acoustics_Case_Study.xlsx` | S1210 aerofoil and slat coordinates (127 mm chord), multi element set up, transient flow results, acoustic study and time step calculations |

The Fluent case and data files (over 200 MB) are too large for GitHub and are kept offline.

## Tools
ANSYS Fluent (LES, k omega SST, DES, FW-H), Excel
